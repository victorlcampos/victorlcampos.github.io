Seu terminal, sem ponto cego. CPU de verdade (80%, nunca 800%), memória do jeito que o SO conta, discos e temperatura — mais quanto da sua cota de IA já foi. Cabe até numa tirinha de 1 linha.

  • CPU como fração da máquina + cada núcleo + load como % dos cores
  • Painel AI limits: Claude Code e Codex, sessão de 5h + semana, com countdown
  • 50 temas, layout que se recalcula a cada resize, <1% de CPU, PT/EN

meridian

Nunca mais erre um fuso. Dígitos gigantes, uma aba por cidade, mapa-múndi com lado da noite, clima da próxima hora e seu próximo evento — com alarmes que fazem a tela piscar.

  • 34.000 cidades, PT/EN, acentos opcionais: sao paulo, Tóquio, Nova Iorque
  • Clima Open-Meteo + Calendário do Mac / iCal com lembrete de 5 min
  • Feito para tiling WM: redimensionou, o layout seguiu. Tudo salvo a cada toque.

  • edit / cut / speed / crop / append / write / convert em um comando
  • Binários p/ Mac / Linux / Windows + aditor --update. Site próprio no ar.
