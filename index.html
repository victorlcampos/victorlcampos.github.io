#1 · 26 set 2026 · Rust · Terminal HUD

vitals

O htop perdeu a barriga. Cabeçalho do htop sem a lista de processos — CPU de verdade (80%, nunca 800%), memória do jeito que o SO conta, swap, discos, temperatura — mais quanto da sua cota de IA já foi. E cabe até numa tirinha de 1 linha.

  • CPU como fração da máquina + cada núcleo + load como % dos cores
  • Painel AI limits: Claude Code e Codex, sessão de 5h + semana, com countdown
  • 50 temas, layout que se recalcula a cada resize, <1% de CPU, PT/EN

#2 · 25 set 2026 · Rust + ratatui · World Clock

meridian

Que horas são onde importa? Um relógio de terminal com dígitos gigantes, uma aba por cidade, mapa-múndi ASCII com lado da noite, clima da próxima hora, seu próximo evento — e alarmes que fazem a tela piscar.

  • 34.000 cidades, PT/EN, acentos opcionais: sao paulo, Tóquio, Nova Iorque
  • Clima Open-Meteo + Calendário do Mac / iCal com lembrete de 5 min
  • Feito para tiling WM: redimensionou, o layout seguiu. Tudo salvo a cada toque.

#4 · 08 set 2026 · Rust · Agentic Video ★2

aditor FROM AGENT ACTION → FINISHED VIDEO

Seu agente resolve. O aditor prova. Capture a aba exata do Chrome, grave demos sem o chrome do browser, corte, acelere, mute — tudo por CLI com --json, IDs explícitos e exit codes que automação entende.

  • tabs / record / screenshot / stop por tab ID ou seletor CSS exato
  • edit / cut / speed / crop / append / write / convert em um comando
  • Binários p/ Mac / Linux / Windows + aditor --update. Site próprio no ar.
